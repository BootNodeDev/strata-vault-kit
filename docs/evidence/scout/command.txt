Step 2: git hook for a dylint bug
---------------------------------
Scout builds a dylint driver at run time. dylint_driver 4.1.2 clones
https://github.com/rust-lang/rust-clippy and checks out the branch "master".
Upstream renamed that branch to "main", so without help the driver build fails with:
  Error: `revparse_ext` failed for `master` ... revspec 'master' not found
The hook below only creates a local "master" branch in that clone. It does not
change Scout, its detectors or the code under analysis.

<scratch>/scout/git-hooks/post-checkout:
  #!/bin/sh
  case "$(git remote get-url origin 2>/dev/null)" in
    *rust-lang/rust-clippy*)
      git rev-parse -q --verify refs/heads/master >/dev/null || git branch master HEAD ;;
  esac
  exit 0
